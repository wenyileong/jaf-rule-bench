JAF Rule Bench 1.1.0

This is the first published release of version 1. Version 1 is a validation-ready instrument. It can test the model against observed facts, and every method is proven on synthetic data before any real data are used. It contains **no results about real countries**; those belong to a later empirical piece.

**New in 1.1: your files**
- A "Your files" tab shows every result the program has saved, and a copy of every workbook or record you have loaded, in one library folder.
- Preview tables, workbooks, text and saved results inside the program; each saved result records the fingerprint (SHA-256) of its files, so any later change is detected.
- Make folders, rename, move and copy; every change shows what will happen first, deleting goes to a Trash you can restore from, and the most recent change can be undone. Every action is logged, including one that stops partway.
- Take results to another computer as a single checked package, or move the whole library to another drive or a USB stick (copied and verified before the switch; the old folder is left untouched).
- The local engine now accepts changes only from its own interface, and the interface runs only its own script.
- Two independent reviews (of the file manager, then of the whole program) found issues that could lose files, crash a task or mislead; all were fixed before release.

**New in 1.0: the "Test against data" tab**
- Describe versions of the law to compare (episodes). Two designs are supported: a single reform, such as India's 2022 regime, and staggered adoption of automatic exchange of information, such as the CARF waves.
- Record the facts observed under each version and their margins of error. Mark each fact as a target (used to fit) or a holdout (kept back to test predictions).
- Measurement model: exchange volume is adjusted for wash trading and turnover; holdings are used directly.
- Check whether the facts can pin the model's settings down. Estimation is refused if they cannot.
- Prove the estimator on known settings (recovery test).
- Estimate the settings and test the predictions for the facts held back.
- Freeze the design for pre-registration and check later work against it.

**Also**
- Rates that cycle between two near-equal revenue peaks are now accepted as an approximate equilibrium, and the revenue any state forgoes is reported. Rankings and the findings register are unchanged.
- The specification has been rewritten for the current model (Part B), and there is a new user guide.
- An independent review of version 1.0 found ten issues; all ten were fixed.
- New program icon. The executable is built, and the 70 acceptance tests and a smoke test of the program are run, on GitHub's Windows runners.
- Workbooks from 0.4 load unchanged.

**Download:** `JAF_Rule_Bench_1.1.0_windows.zip`. Unzip it and double-click `JAF_Rule_Bench.exe`. The program is not code-signed, so Windows may warn that it is unrecognised: choose "More info", then "Run anyway".
